# Home Back Exit

A lightweight Kodi addon that opens the Shutdown Menu when the Back button is pressed on the Home screen.

## Features

- Home screen only
- Opens the Shutdown Menu
- No background service
- No Python code
- Works with Kodi 21 (Omega)

## Installation

1. Download the ZIP.
2. In Kodi, go to **Settings → Add-ons → Install from ZIP file**.
3. Select the downloaded ZIP.
4. Restart Kodi.
